The caption above (or below) a grouped list section. Fills its container.

**You provide** `label`, and `indent` to line it up with the cell text instead of the list edge.

- Use sentence case and a few words («Налаштування», «Спосіб отримання»).
- Set it 8px (`space-2`) above its block, as the shipped screens do: `Card`'s `caption` prop does this for you.
- A caption too long for one line wraps.
