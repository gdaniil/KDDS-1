Switches between two to five views of the same content. 32px tall; the segments share the width.

**You provide** `options` (2–5 short labels), `value` (an index or a label) and `onChange`, which gets the same kind of value.

- Use it for views of one thing («Список», «Мапа»), not for navigation between unrelated screens.
- Labels stay one word where possible; a label too long for its segment ends with «…».
